# Flex Basis

Đầy đủ ví dụ px, auto, initial, inherit, column, phần trăm và basis kết hợp grow. Basis là kích thước trước khi grow/shrink phân phối không gian.

## Chạy
Mở index.html trong trình duyệt. Ví dụ cố định kích thước có khung cuộn ở màn hình nhỏ; các bài bố cục có media query.
